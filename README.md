# John Earl Gabral — Personal Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript. It features a dark slate theme with cyan and indigo accents.

## Portfolio sections

- Home and introduction
- About and education
- Technical skills
- Projects: Student Task Manager, Face Detection System, and UBMSConnect
- Seminars, webinars, certificates, and training
- Contact information

## Run locally

Open `index.html` in a browser, or serve this folder with a local development server such as the VS Code Live Server extension.

## Project files

- `index.html` — portfolio content and structure
- `style.css` — theme, layout, and responsive styles
- `script.js` — mobile navigation, active section indicator, and current footer year
- `assets/` — profile, project, seminar, and certificate images

## Publish with GitHub Pages

1. Push the project files to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. After GitHub Pages finishes deploying, open the URL shown in the Pages settings.
